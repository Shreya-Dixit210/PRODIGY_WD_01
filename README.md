# Chia Taj View Café 🏛️☕
A responsive landing page for a real rooftop café in Agra with a stunning Taj Mahal view, built using HTML5, CSS3 and Vanilla JavaScript. This project focuses on recreating a premium, real-world café website while practicing modern front-end design concepts.

## 📌 Project Overview
The Chia Taj View Café Landing Page is a front-end project that demonstrates how real-world restaurant and hospitality websites are structured and styled. It includes a luxury UI, smooth animations, interactive sections, and a fully responsive design suitable for all screen sizes.

---

## ✨ Features
* Responsive café landing page inspired by premium hospitality websites
* Full-screen Taj Mahal hero background with cinematic zoom animation
* Floating gold particle effects on the hero section
* Fixed navbar with smooth scroll and shrink-on-scroll effect
* Bottom-fixed scrolling offers ribbon visible across all sections
* Interactive 5-tab menu — Breakfast, Mains, Chinese, Beverages & Specials
* Veg / Non-veg indicators on all menu items
* Online table booking form with time slots, guest count & seating preference
* Experience photo gallery with hover reveal effects
* Embedded Google Maps for café location
* Guest reviews section with real testimonials
* Mobile responsive with hamburger menu for smaller screens
* Clean, beginner-friendly and well-structured code
